# Grocery-sales-analysis
Grocery Sales analysis with Power BI.
I've got a penchant for turning messy numbers into stories, so when I got my hands on a grocery sales dataset from Blinkit, I knew I had to dig in. 
It started with a simple question: what is this data trying to tell me?
I connected the data in Power BI and quickly realized it wasn't going to talk without a little cleanup. Utilizing Power Query feature, I fixed data types and standardized inconsistent values, like the Fat Content labels that were spelled five different ways. 
Once the data was clean, I built relationships between the tables so everything could speak to each other.
Then came the interesting part: DAX. I wrote measures for Total Sales, Average Sales, and Number of Items, the building blocks that let me start asking real business questions:
Which outlet locations drive the most revenue?
Which product categories are carrying the business?
Does outlet size or type change how items perform?
The answers showed up in the final dashboard: $1.20M in total sales across 8,523 items, Tier 3 locations leading in revenue, Supermarket Type1 outlets pulling the most weight, and Fruits & Vegetables and Snack Foods topping the product list. I also added slicers and used the bookmark feature to set up a clear button for refreshing so to make it as interactive as possible.
What I loved most wasn't the charts. It was the moment the data stopped being rows and columns and started being a story someone could act on.
